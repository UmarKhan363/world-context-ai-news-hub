## Run locally
Open `index.html` in a web browser. For best results, use VS Code and its Live Server extension, but it is not required.

## Publish to GitHub
1. Sign in to GitHub and create a **new public repository** named `ai-news-hub`.
2. Do not initialize it with a README if you plan to upload this project's existing README; either choice is fine as long as you avoid duplicate-file conflicts.
3. Extract the ZIP on your computer.
4. Open the repository and choose **Add file → Upload files**.
5. Upload all project files and folders from inside `ai-news-hub` (not just the ZIP file).
6. Commit the files to the `main` branch.

## Deploy free with GitHub Pages
1. Open your repository → **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for the Pages deployment to complete.
5. Your URL will usually be `https://YOUR-USERNAME.github.io/ai-news-hub/`. Replace `YOUR-USERNAME` with your actual GitHub username.
6. Test the live site and click the navigation links. Submit both the repository URL and live URL to your instructor.

## Important notes
- The site is original sample work generated specifically for this assignment; review and personalize it before submission.
- The article text is illustrative educational copy, not verified breaking news. Add sources if your instructor expects researched news reporting.
- The contact form is a static visual demonstration. HTML/CSS alone cannot process or store submissions.
- The design imports Manrope and DM Mono from Google Fonts when internet access is available. The site still has fallback fonts.
- No website has been uploaded or deployed by this project generator. You must perform the GitHub and hosting steps above.
